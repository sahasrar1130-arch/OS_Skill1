STRACE SYSTEM CALL ANALYSIS

Command:
strace -e trace=openat,read,write,close cat sample.txt

System Call Analysis:

openat() - Opens sample.txt for reading.
read() - Reads the contents of the file.
write() - Displays the file contents on the terminal.
read() = 0 - Indicates the end of the file.
close() - Closes the opened file.

Kernel Services:
openat() -> File Management
read() -> File I/O
write() -> I/O Management
close() -> File Management

Conclusion:
The strace utility traces the system calls made by the cat command.
The cat program requests services from the Linux kernel through
system calls. The kernel opens the file, reads its contents,
writes the contents to the terminal, and finally closes the file.
